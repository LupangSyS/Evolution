# Evolution วิวัฒนาการ — เกมการ์ดออนไลน์

เกมการ์ดวิวัฒนาการสัตว์ (อิงกติกา Evolution ชุดพื้นฐาน) สำหรับผู้เล่น 2–6 คน เล่นผ่านเบราว์เซอร์
ผู้เล่นดูแลสปีชีส์สัตว์ของตัวเอง ใส่ลักษณะ (trait) ให้วิวัฒนาการ หาอาหาร และล่ากันเอง ใครเก็บอาหารได้มากที่สุดชนะ

> เล่นได้ครบ: หน้าแรก → ห้องรอ → โต๊ะวงรี → ผลเกม (ภาษาไทย รองรับมือถือจอ 400px และเดสก์ท็อป)

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm start       # เปิดเซิร์ฟเวอร์ที่ http://localhost:3000
npm test        # จำลองเกมบอทล้วน 300 เกม (2–6 คน) + ทดสอบกฎ + ทดสอบห้องผ่าน socket + ตรวจภาพ
npm run test:ui # เปิดหน้าเว็บจริงใน Chromium (เดสก์ท็อป 1280×800 + มือถือ 400px) เล่นจนจบ ตรวจ error และเลย์เอาต์
```

`test:ui` ใช้ Playwright — ถ้ายังไม่มีเบราว์เซอร์ให้รัน `npx playwright install chromium` ครั้งแรก
ภาพหน้าจอจากการทดสอบถูกบันทึกที่ `test-results/`

## หน้าจอเล่นเกม

- **โต๊ะวงรี** ผู้เล่นนั่งรอบโต๊ะตามลำดับการเล่น ที่นั่งของคุณอยู่ล่างสุด มีกรอบทองและป้าย "คุณ"
- ผู้เล่นที่ถึงตาจะมีกรอบเรืองแสงสีเหลือง · ลูกศร **แดง** = นักล่าโจมตีเหยื่อ, **เขียว** = กินพืชจากแหล่งน้ำ, สปีชีส์ที่เพิ่งถูกเล่นการ์ดใส่จะเรืองแสงสีทอง
- สปีชีส์บนโต๊ะแสดง ขนาดตัว·ประชากร, อาหารที่กินแล้ว (●) และสีของลักษณะ (สีเทา = ยังคว่ำ) · แตะเพื่อดูรายละเอียด
- การ์ดในมือ: ภาพ → ชื่อ → ประเภท → ผลโดยย่อ ตัวเลขอาหารอยู่มุมขวาบน · ปุ่ม **i** เปิดกติกาเต็ม
- ตัวจับเวลาแต่ละคำสั่ง, บันทึกเกม, แชท และหน้าผลเกมพร้อมปุ่ม "เล่นอีกครั้ง"


ตัวแปรสภาพแวดล้อม: `PORT` (ค่าเริ่มต้น 3000), `BOT_DELAY` (ms ที่บอทใช้คิด ค่าเริ่มต้น 900)

## ขึ้นเว็บฟรีด้วย Render

1. สมัคร/เข้าสู่ระบบ https://render.com ด้วยบัญชี GitHub
2. กด **New → Web Service** แล้วเลือก repo `Evolution`
3. ตั้งค่า:
   - **Branch**: `main`
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. กด **Create Web Service** รอสักครู่ จะได้ลิงก์แบบ `https://evolution-xxxx.onrender.com` ส่งให้เพื่อนได้เลย

ข้อควรรู้ของแผนฟรี: ถ้าไม่มีคนใช้ ~15 นาที เซิร์ฟเวอร์จะหลับ (เปิดครั้งแรกรอ ~1 นาที)
และทุกครั้งที่เซิร์ฟเวอร์หลับหรือรีสตาร์ท **ห้องที่เล่นอยู่จะหายไป** เพราะเก็บสถานะไว้ในหน่วยความจำ
Render จะ deploy ใหม่อัตโนมัติทุกครั้งที่มีการ merge เข้า `main`

## 🖼 ภาพประกอบ (สร้างจากโค้ด บันทึกถาวร)

ภาพทุกภาพ — การ์ดลักษณะ 17 แบบ, หลังการ์ด, ผ้าปูโต๊ะ และแหล่งน้ำ — **วาดจากโค้ดทีละพิกเซล (RGB)** แบบ pixel art
ด้วยตัวสร้างภาพใน `public/artgen/` (ไม่ใช้ AI ไม่ใช้ภาพจากเกมจริง) แล้วบันทึกถาวรเป็นไฟล์ PNG ใน `public/art/`
พร้อม `manifest.json` ที่เก็บลายนิ้วมือ SHA-256 ของทุกไฟล์

- ดูภาพพร้อมข้อมูลการ์ดได้ที่ `/gallery.html` (ติ๊ก "วาดใหม่สดจากโค้ดเพื่อเทียบ" ให้เบราว์เซอร์วาดใหม่แล้วเทียบกับไฟล์ทีละพิกเซล)
- ภาพเป็นไฟล์คงที่ ไม่มีหน้าแก้ไข/อัปโหลด และเซิร์ฟเวอร์ไม่มี API สำหรับเขียนไฟล์
- `npm test` ตรวจว่าไฟล์ทุกไฟล์ตรงกับที่ตัวสร้างภาพวาดทุกพิกเซล — ถ้ามีใครแก้ไฟล์ภาพ การทดสอบจะไม่ผ่าน
- ผู้ดูแลที่ต้องการเปลี่ยนภาพ: แก้ `public/artgen/designs.js` แล้วรัน `npm run build:art` และ commit (ตรวจอย่างเดียว: `npm run build:art -- --check`)

## ระบบห้อง

- สร้างห้องได้รหัส 4 ตัวอักษร เชิญเพื่อนด้วยลิงก์ `?room=CODE`
- หัวห้องเพิ่ม/เตะบอท และกดเริ่มเกม (2–6 คน) มีแชทในห้อง
- **กลับเข้าเกม**: เบราว์เซอร์เก็บ token ไว้ใน localStorage รีเฟรชหรือเน็ตหลุดแล้วกลับมา จะได้ที่นั่งเดิมพร้อมคำสั่งที่รออยู่
  - ถ้าหลุดแล้วถึงตาคุณ ระบบรอ ~12 วินาที แล้วให้บอทตัดสินใจแทนเฉพาะครั้งนั้น
  - กด "ออก" ระหว่างเกม = ยกที่นั่งให้บอทเล่นแทนถาวร
- จบเกมแล้วหัวห้องกด "เล่นอีกครั้ง" เพื่อกลับห้องรอ

## กติกาโดยย่อ

แต่ละรอบมี 5 ช่วง:

1. **แจกการ์ด** — คนละ 3 ใบ + 1 ใบต่อสปีชีส์ (ถ้าไม่มีสปีชีส์เหลือ ได้สปีชีส์ใหม่ขนาด 1 ประชากร 1)
2. **เลือกการ์ดอาหาร** — ทุกคนคว่ำการ์ด 1 ใบลงแหล่งน้ำ
3. **เล่นการ์ด** (ทุกคนพร้อมกัน) — ใส่เป็นลักษณะแบบคว่ำ (สูงสุด 3 ลักษณะ/สปีชีส์ ห้ามซ้ำ แทนที่ของเดิมได้)
   หรือทิ้งเพื่อ เพิ่มขนาดตัว / เพิ่มประชากร (สูงสุด 6) / สร้างสปีชีส์ใหม่ทางซ้ายหรือขวา
4. **เปิดการ์ดอาหาร** — เปิดลักษณะ, ขยายพันธุ์เร็ว → คอยาว → ไขมันสะสม, แล้วรวมตัวเลขอาหารใส่แหล่งน้ำ (ไม่ต่ำกว่า 0)
5. **หาอาหาร** — ผลัดกันทีละสปีชีส์: สัตว์กินพืชกินพืช 1 จากแหล่งน้ำ (ต้องกินถ้ายังหิวและมีอาหาร),
   นักล่าโจมตีสปีชีส์ที่ตัวเล็กกว่า (ไม่บังคับ) เหยื่อเสียประชากร 1 นักล่าได้เนื้อเท่าขนาดตัวเหยื่อ

จบรอบ: ประชากรลดลงเท่าอาหารที่กินได้ อาหารลงถุง (คะแนน) สปีชีส์ที่ไม่ได้กินเลยสูญพันธุ์ (จั่วการ์ดเท่าจำนวนลักษณะ)

**จบเกม**: เมื่อกองจั่วหมด สับกองทิ้งกลับมาแจกต่อ และเกมจบเมื่อจบรอบนั้น
**คะแนน** = อาหารในถุง + ประชากรที่รอด + จำนวนลักษณะที่รอด (เสมอ → ดูอาหารในถุง → ยังเสมอ ชนะร่วมกัน)

การ์ด 129 ใบ: กินเนื้อ 17 ใบ + ลักษณะอื่นอย่างละ 7 ใบ (16 ชนิด) — ดูรายละเอียดใน `server/game/cards.js`

## โครงสร้าง

```
server/
  index.js        HTTP + Socket.IO (+ /api/cards ฐานข้อมูลการ์ด อ่านอย่างเดียว)
  rooms.js        ระบบห้อง, token/rejoin, บอทแทนคนที่หลุด/ออก, แชท, ส่งสถานะรายคน
  game/
    engine.js     กฎเกม (async state machine — ทุกการตัดสินใจคือ prompt ที่ await)
    cards.js      ข้อมูลการ์ด 17 ลักษณะ (ชื่อไทย, ผล, ตัวเลขอาหาร)
    bot.js        บอทที่เล่นตามกฎ (ประเมินค่าการกระทำ)
public/
  index.html      หน้าเกม
  app.js          ไคลเอนต์: หน้าแรก, ห้องรอ, โต๊ะวงรี, การ์ดในมือ, คำสั่ง, ลูกศร, ผลเกม
  style.css       สไตล์ทั้งหมด (มือถือก่อน)
  gallery.html    คลังภาพ + ฐานข้อมูลการ์ด (อ่านอย่างเดียว)
  cardface.js     หน้าการ์ด (ภาพ → ชื่อ → ประเภท → ผล) ใช้ร่วมกันระหว่างเกมและคลังภาพ
  artgen/         ตัวสร้างภาพ pixel art (raster.js, designs.js) ใช้ได้ทั้ง Node และเบราว์เซอร์
  art/            ภาพที่สร้างแล้ว (PNG) + manifest.json — ห้ามแก้ด้วยมือ
scripts/
  build-art.js    สร้าง/ตรวจสอบภาพทั้งหมด
  png.js          ตัวเข้ารหัส PNG
test/
  art.test.js     ตรวจว่าภาพตรงกับตัวสร้างภาพ + เขียนทับผ่าน HTTP ไม่ได้
  engine.test.js  จำลองเกมบอทหลายร้อยเกม + ทดสอบกฎ + ตรวจคำตอบที่ไม่ถูกต้อง + rejoin
  server.test.js  end-to-end ผ่าน socket: สร้างห้อง → เข้าห้อง → บอท → เริ่ม → หลุด → กลับที่นั่งเดิม
  ui/             ทดสอบหน้าเว็บจริงใน Chromium (Playwright) เดสก์ท็อป + มือถือ
```

เซิร์ฟเวอร์เป็นผู้ตัดสินทั้งหมด ผู้เล่นแต่ละคนได้รับเฉพาะข้อมูลที่ตัวเองควรเห็น
(ไม่ส่งมือ ถุงอาหาร การ์ดอาหารที่คว่ำ หรือลักษณะที่ยังคว่ำของผู้เล่นอื่น)
สถานะเกมเก็บในหน่วยความจำ — **ถ้ารีสตาร์ทเซิร์ฟเวอร์ ห้องที่เล่นอยู่จะหายไป**
